EasyInput V2.0 · ESP32-S3 · Online

说出歌名，音乐在板上播放。

开发板通过 Wi-Fi 录音，阿里云百炼识别歌曲关键词，GD Studio API 解析播放链接，ESP32 自己解码 MP3 并从扬声器输出。旋钮调音量/暂停，D1-D5 跟随阶段和节拍变化。

Controls / 操作

在线模式内 S1-S8 暂时屏蔽原有快捷键，退出后恢复。

进入 / 退出

旋钮短按双击，两次间隔 251–500 ms；再次双击退出。

语音搜索

按任意 S1-S8 开始录音，松开结束；最长 10 秒，识别后自动搜索并播放。

暂停与音量

单击旋钮暂停/继续；左旋降低、右旋提高，默认 15%，每格 5%。

切歌

播放中再次按任意 S1-S8 重新录音并按新查询切歌。

灯效

D1-D5 显示录音、识别、搜索、解析、起播，再变为彩色节奏呼吸。

板载输出

电脑只写入配置；Wi-Fi 音频流由 ESP32 解码并从开发板扬声器播放。

Setup / 配置

阿里云凭据由用户自行申请和承担费用；占位符不能直接使用。

1 · 阿里云

百炼创建 Workspace，开通实时 ASR，取得 API Key 和 Workspace ID。默认模型为 qwen-audio-3.0-asr-flash-streaming。

2 · 写入设备

通过兼容 USB/BLE 配置工具写入 `ai_keyboard.v1` JSON；凭据保存到 NVS，不会出现在状态回执或日志。

3 · 网络

同时写入 Wi-Fi SSID/密码。GD Studio API 和上游音乐源必须可达，版权由使用者自行确认。

{
  "schema": "ai_keyboard.v1",
  "wifi_ssid": "YOUR_WIFI_SSID",
  "wifi_password": "YOUR_WIFI_PASSWORD",
  "online_music_enabled": true,
  "online_music_asr_api_key": "YOUR_ALIYUN_API_KEY",
  "online_music_asr_workspace_id": "YOUR_WORKSPACE_ID"
}

Build / 构建

默认构建在线音乐能力，不嵌入商业歌曲；需要 ESP-IDF 5.5.5 和 ESP32-S3 工具链。

git clone https://github.com/HachikoJ/easyinput-music-firmware.git
cd easyinput-music-firmware
idf.py build
cmake -S host_test -B build-host -DCMAKE_BUILD_TYPE=Debug
cmake --build build-host --parallel
ctest --test-dir build-host --output-on-failure
