EasyInput V2.0 · ESP32-S3 · Offline

音乐在板上解码，灯光跟着节奏呼吸。

两首 Ogg Opus 音乐存储在本地 Flash，由开发板直接解码并播放。旋钮控制音量与暂停，S1-S8 控制播放列表，D1-D5 输出多色节奏灯效。

查看按键逻辑打开源码

Controls / 操作

进入音乐模式后，S1-S8 原有快捷键暂时让位给播放控制。

模式

旋钮短按双击进入或退出音乐模式。

播放

任意 S1-S8 开始第一首；再次按下切换下一首并无限循环。

暂停与音量

单击旋钮暂停/继续；左旋降低、右旋提高，默认 15%。

灯效

D1-D5 根据音频 RMS 与节拍输出多色动态呼吸。

本地解码

音频从板载 Flash 读取，播放链路不依赖 Wi-Fi 或电脑。

容量边界

测试 App 分区保留 49% 空间，DIRAM 余量 153,661 bytes。

Build / 构建

音乐文件是外部输入，不随公开源码发布。请使用有授权的 Ogg Opus 文件。

idf.py -B build-music \
  -D EASY_INPUT_MUSIC_PLAYER=ON \
  -D EASY_INPUT_SPEAKER_ASSETS_PRODUCT=OFF \
  -D EASY_INPUT_SPEAKER_DIAGNOSTIC=OFF \
  -D EASY_INPUT_MUSIC_TRACK_0="/absolute/path/track-0.ogg" \
  -D EASY_INPUT_MUSIC_TRACK_1="/absolute/path/track-1.ogg" \
  build
