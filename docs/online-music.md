# 在线音乐完整手册

本文对应默认的 `EASY_INPUT_ONLINE_MUSIC=ON` 构建。在线音乐不是板载曲库：开发板负责录音、联网、MP3 解码和扬声器输出；电脑只负责配置，声音不会从电脑播放。

## 1. 依赖和边界

一次播放需要同时满足：

- EasyInput V2.0 / ESP32-S3 已烧录本项目固件；
- 开发板已经保存可用的 Wi-Fi SSID 和密码；
- 阿里云百炼实时 ASR 的 API Key 与 Workspace ID 已配置；
- GD Studio API、上游音乐源和返回链接当时可用；
- 使用者拥有所请求音乐及其录音、表演和传播所需的权利。

阿里云只用于语音识别和歌曲关键词提取，不提供歌曲。歌曲搜索和播放链接由 GD Studio API 完成，实际音频来自上游音乐源。

## 2. 申请阿里云凭据

1. 登录阿里云并进入百炼控制台，创建或选择项目/Workspace。
2. 在模型或应用权限中开通实时语音识别，确认项目可调用 `qwen-audio-3.0-asr-flash-streaming`。
3. 在 API-KEY 管理中创建一枚专用 Key，并限制权限、设置额度和有效期。
4. 记录 Workspace ID 和 API Key。只在本地配置工具中粘贴，绝不要写入仓库或提交到 Git。

阿里云控制台的名称、套餐、地域和计费规则可能变化，以当前官方页面为准。费用、配额和超额责任由使用者承担；本项目不代收费用，也不保证“每月只需几毛钱”。

## 3. 写入 Wi-Fi 与 ASR 配置

固件接受 `ai_keyboard.v1` 配置 JSON。最小在线音乐配置如下：

```json
{
  "schema": "ai_keyboard.v1",
  "wifi_ssid": "YOUR_WIFI_SSID",
  "wifi_password": "YOUR_WIFI_PASSWORD",
  "online_music_enabled": true,
  "online_music_asr_api_key": "YOUR_ALIYUN_API_KEY",
  "online_music_asr_workspace_id": "YOUR_WORKSPACE_ID"
}
```

`YOUR_*` 只是占位符。API Key 最长 192 字节，Workspace ID 必须非空且不超过 96 字节。配置通过 USB/BLE 私有配置通道或已配置主机的 Wi-Fi 配置端点分块发送，固件校验 CRC 后保存到 NVS；状态回执不会返回密钥。仓库不包含桌面 companion，使用者需要自己的兼容配置工具。

如工具要求先打开配置窗口，按住旋钮约 3 秒进入配置流程，再按工具提示发送 JSON；不要在未确认工具实现的情况下手工写 Flash。Wi-Fi 配置端点只适合受信任的本地网络，当前 UDP 控制协议没有密码学认证。

## 4. 构建和烧录

1. 安装 ESP-IDF **5.5.5**，目标为 `esp32s3`；项目路径和 IDF 路径不要包含空格。
2. 在仓库根目录运行 `idf.py build`，看到 `Project build complete` 后再烧录。
3. 连接数据 USB 线，先只读识别目标芯片和 MAC，再执行 `idf.py -p <PORT> flash`。烧录会覆盖旧固件，不要使用 `erase-flash` 作为常规步骤。
4. 如果自动下载失败，EasyInput V2.0 的下载动作是开机状态短按并松开一次 BOOT；重新枚举后重新核对设备，再烧录。不要按住 BOOT 上电，也不要把 GPIO0 当业务键。
5. 若本轮手动进入下载模式，烧录结束后关闭全部供电，再正常开机，且不要再次按 BOOT。烧录退出码为 0 只证明写入完成，仍需观察应用启动和功能。

构建、烧录和实板运行是三种不同证据。主机逻辑测试命令见根 README，当前公开仓库不会上传带真实凭据的 `sdkconfig`、镜像或日志。

## 5. 在线播放完整流程

1. **进入**：旋钮短按两次，两次按压间隔需为 251–500 ms。成功后进入等待命令状态；快速双击（小于 251 ms）保留给离线音乐手势。再次以同样间隔双击可退出。
2. **开始录音**：进入模式后按下任意 S1–S8。D5 变橙表示准备录音，随后 D5 脉冲蓝表示正在录音；最长录音 10 秒。
3. **结束录音**：松开按键，或等待 10 秒超时。D5 变绿，D4 脉冲蓝表示正在等待阿里云识别结果。
4. **搜索歌曲**：识别文本会去掉“播放”“我想听”等前缀，剩余内容作为关键词。D4 完成后 D3 脉冲蓝表示向 GD Studio 搜索，D3 变绿后 D2 脉冲蓝表示解析播放链接。
5. **开始播放**：D2 变绿后 D1 脉冲蓝表示正在建立 HTTPS 音频流；成功后五颗灯切换到彩色节奏呼吸，板载扬声器播放 MP3。播放流在 PSRAM 中使用约 512 KiB 编码预缓冲，避免短暂网络抖动立刻断音。
6. **重新搜索/切歌**：播放中按任意 S1–S8 会停止当前流并开始一次新的语音搜索，不会把按键传给 USB、BLE、PTT 或亮度功能。准备、识别和解析期间的其他按键只被消费，不会重复启动任务。
7. **自然结束**：歌曲结束后进入等待下一首状态，灯效停止并回到等待提示。30 秒内没有输入时，固件会用同一关键词尝试下一页搜索结果，最多尝试 3 页；失败则进入重试窗口。

## 6. 旋钮、音量和灯效

- 播放中旋钮向左旋转降低音量，向右旋转提高音量，每格 5%，范围 0–100%，进入模式默认 15%。
- 旋钮单击暂停，再次单击继续。由于要区分双击退出，单击动作会在双击窗口结束后生效，最多约 500 ms。
- D1–D5 进度映射：D5 录音，D4 识别，D3 搜索，D2 解析 URL，D1 起播。
- 进度灯：橙色=准备/等待，脉冲蓝=当前阶段，绿色=完成，红色闪烁约 1.5 秒=失败，橙色常亮=等待重试，未开始阶段熄灭。
- 播放成功后，D1–D5 每约 30 ms 更新彩色色相，亮度由音频 RMS 和节拍估计驱动；暂停时保留低亮彩色静态灯，退出时熄灭。
- 独立状态灯在等待用户时显示等待态，识别/解析时显示运行态，凭据缺失或运行时错误显示短暂失败态。

## 7. 退出和自动超时

再次短按双击旋钮即可退出。退出会停止 HTTPS 流和 ASR、释放扬声器与 Wi-Fi 音频占用、清除在线进度和灯效，并恢复 S1–S8 的默认快捷键、语音输入和亮度功能。

连续 30 分钟没有在线音乐活动会自动退出；识别或播放失败后进入 30 秒重试窗口，窗口结束自动退出。退出过程不会删除 NVS 中的 Wi-Fi 或 ASR 凭据。

## 8. 故障排查

| 现象 | 检查顺序 |
| --- | --- |
| 双击无反应 | 确认两次间隔 251–500 ms；小于 251 ms 是离线手势；不要在按住旋钮时旋转。 |
| 进入后立即失败 | 检查 `online_music_enabled`、API Key、Workspace ID 是否都已写入；状态只会报告 `credentials_configured=false`，不会显示密钥。 |
| D5 红闪、没有识别 | 检查 Wi-Fi、阿里云 Key 权限/额度、Workspace 地域和麦克风；常见错误包括 `wifi_unavailable`、`connect`、`task_start_timeout`、`empty_transcript`。 |
| 识别成功但没有音乐 | 检查关键词是否明确、GD Studio API 是否可达、上游 NetEase 源是否返回结果；日志阶段包括 `catalog_search` 和 `catalog_url`。 |
| D1 红闪或无声音 | 检查 Wi-Fi 流量和信号、扬声器电源仲裁及流 worker；日志阶段包括 `wifi_downlink`、`stream_worker`、`stream_http`、`stream_decode`、`stream_read`。 |
| 按键影响系统快捷键 | 说明尚未真正进入在线模式，或固件不是本仓库构建；在线活动状态下 S1–S8 和旋钮事件应全部被消费。 |
| 播放卡顿 | 先靠近 AP、降低网络并发；播放器已使用 PSRAM 预缓冲，但无法消除上游限速、链接过期或断网。 |

不要把普通启动日志、烧录退出码或“能进入下载模式”当成在线音乐通过证据。应分别记录构建、烧录、应用启动和实际听到声音/看到灯效的结果。

## 9. API 署名、版权和隐私

在线音乐使用 GD Studio Online Music Platform API：<https://music-api.gdstudio.xyz/api.php>。按上游页面说明保留署名 **GD音乐台(music.gdstudio.xyz)**，该 API 按其页面标注的 CC BY-NC 4.0 提供，仅限学习参考、禁止商业使用。该 API 许可不等于任何歌曲、录音、表演、专辑图或播放链接已获授权。

使用者自行承担阿里云费用、GD Studio/上游服务条款、地区限制、请求频率、歌曲版权和再分发责任。录音会通过 HTTPS WebSocket 发送到用户配置的阿里云 ASR；API Key 与 Workspace ID 保存在设备 NVS，不写入状态回执、日志或仓库。请只在你信任的 Wi-Fi 上使用配置和音频控制端点。

## 10. 离线模式区别

离线模式是另一套显式构建：`EASY_INPUT_MUSIC_PLAYER=ON`，使用源码树外的 Ogg Opus 输入并在板载 Flash 中播放，不调用阿里云、GD Studio 或 Wi-Fi。默认在线固件不会自动嵌入歌曲，也不会把电脑变成播放端。两种模式的构建开关、容量边界和版权要求不要混用。
